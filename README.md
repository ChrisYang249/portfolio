# Christopher Yang: portfolio

Static site (HTML, CSS, JavaScript). No build step.

- **Change the words:** edit `content.js` only. Any field set to `TODO` shows a dashed
  "Chris to write" box until it is filled in.
- **Change the look:** `styles.css`.
- **Preview locally:** run `python3 -m http.server` in this folder and open http://localhost:8000
- **Hosting:** Render static site (see `render.yaml`). Every push to `main` redeploys.

Font: Schibsted Grotesk (SIL Open Font License), self-hosted in `assets/fonts`.
